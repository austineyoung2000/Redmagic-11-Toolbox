# Redmagic 11 Toolbox 2.7.0

The toolbox gets a redesigned dashboard and updated controls across cooling, lighting, gaming, hardware, profiles, and system pages.

- A dashboard with live cooling information and clear navigation to each section.
- Updated game profiles and per-game trigger mapping, with lighting controls that match LED Zones.
- Redesigned shoulder-trigger controls and safety settings, including intent and hold handling.
- Updated charging, calling, and per-app notification lighting pages.
- Improved page navigation, including returning from Magic Key to Hardware.

Requires a rooted REDMAGIC 11 Pro (NX809J) with compatible vendor interfaces. Install the signed APK over the existing app to retain settings.
